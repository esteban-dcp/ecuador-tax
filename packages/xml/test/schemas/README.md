# Esquemas XSD de prueba

Copias de los XSD publicados por el SRI (https://www.sri.gob.ec/facturacion-electronica, descargados en `docs/official-sri/`)
y del esquema W3C `xmldsig-core-schema.xsd` (sin el bloque DOCTYPE, para poder cargarlo sin red).
Solo se usan en pruebas (no se publican en npm). Propiedad de sus respectivos autores.
